1. HTML 태그까지 통째로 넣고 싶을 때: innerHTML
textContent는 모든 것을 '그냥 글자'로 취급하지만, innerHTML은 문자열 안에 포함된 HTML 태그를 진짜 태그로 인식해서 화면에 그려줍니다.

textContent: <b>안녕</b> → 화면에 그대로 <b>안녕</b>이라고 출력됨

innerHTML: <b>안녕</b> → 화면에 안녕(굵은 글씨)으로 출력됨

2. 스타일(색상, 크기 등)을 바꾸고 싶을 때: style
JS 파일 안에서 CSS를 직접 조절하는 방법입니다. 아까 배운 카멜 케이스가 여기서 아주 중요하게 쓰여요!

el.style.color = 'red'; (글자색 변경)

el.style.backgroundColor = 'blue'; (배경색 변경 - CSS의 background-color가 카멜 케이스로 바뀜!)

el.style.fontSize = '20px'; (글자 크기 변경)

3. 클래스(class)를 넣었다 뺐다 하고 싶을 때: classList
직접 스타일을 하나하나 바꾸기보다, CSS 파일에 미리 정의해둔 클래스를 붙였다 떼었다 하는 게 훨씬 깔끔합니다. 이 방식을 실무에서 가장 많이 써요.

el.classList.add('active'); (active 클래스 추가)

el.classList.remove('hidden'); (hidden 클래스 제거)

el.classList.toggle('dark-mode'); (있으면 없애고, 없으면 생기게 함)

4. 속성(href, src 등)을 다룰 때: setAttribute
이미지의 주소(src)나 링크의 주소(href)를 바꿀 때 사용합니다.

img.setAttribute('src', 'profile.png'); (이미지 경로 변경)

link.setAttribute('href', '[https://google.com](https://google.com)'); (링크 주소 변경)
